CampusConnect 🎓

CampusConnect is a frontend-only campus activity platform that helps students discover events, join activities and communities, create initiatives, and track their participation through a dashboard.

The project is built using HTML, CSS, and vanilla JavaScript. It is designed as a functional demonstration, with data saved locally in the browser.

✨ Features

- Explore Events: Browse campus activities and view event details.
- Search and Filter: Search events by title, category, location, or description, and filter by category.
- Sort Events: Sort the event list by date or title.
- Join or Leave Events: Register for or leave an activity, with capacity checks.
- Communities: Browse communities and join or leave them.
- Create an Initiative: Submit a new campus activity through a form with input validation.
- Dashboard: View joined activities and participation statistics.
- Local Data Persistence: Save event and participation changes using browser "localStorage".
- Responsive Interface: Layout adapts to desktop, tablet, and mobile screens.
- Demo Reset: Restore the default data and clear locally saved changes.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Browser "localStorage"

🚀 How to Run

1. Download or clone this repository.
2. Open the "CampusConnect" folder.
3. Open "index.html" in a web browser.

No backend, database, package installation, or build process is required for this frontend demo.

💾 Data Storage

CampusConnect uses the browser's "localStorage" to save events, joined events, and joined communities. This allows changes to remain after refreshing the page in the same browser.

Note: The data is stored locally and is not shared between users or devices. Clearing the browser's site data may remove the saved demo information.

⚠️ Project Scope and Limitations

This is a frontend demonstration project. It does not currently include:

- User accounts or authentication
- A backend server or shared database
- Real-time updates between users
- Email or push notifications

Event and community actions are simulated locally in the browser.

🎯 Project Purpose

The project demonstrates how HTML, CSS, and JavaScript can be combined to create an interactive, responsive campus activity interface. It includes DOM manipulation, event handling, form validation, array-based data management, and browser storage.
